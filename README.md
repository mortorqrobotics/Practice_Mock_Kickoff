Practice repository for the fall 2026 Mortorq Robotics mock kickoff based on the 2022 FRC game, <b>Charged Up</b>!

## Instructions
1. Create the motor for the subsystem and assign motor ID integer value in RobotMap.java
2. Create Commands using WPILIB Principles and past code.
3. Create an object of the subsystem class you made. (RobotContainer.java)
4. Assign a button from the Xbox (CommandXBOXController) in RobotContainer.java
